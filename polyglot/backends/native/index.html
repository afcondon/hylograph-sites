purescript-native — C++

Target: native C++ (and a Go variant) · Lineage: source-emitter · By: Andy Arvanitis · Status: established · Repo: andyarvanitis/purescript-native

The long-standing native backend — PureScript to C++, with a companion Go target and an FFI (go-ffi). It borrows native compilation: no VM, direct machine code, C/C++ interop.

Note: our own psgo is a separate, from-scratch Go emitter — distinct from this project's Go variant. The local clone of purescript-native is the reference for the Go column's FFI conventions, though go-ffi tracks an older core-library era, so expect the least coverage here — each gap is a "library coverage" data point for the matrix.
